# GAME_DESIGN — 올림포스 도시 (가제)

> ⚠️ **역사 기록 문서**: 이 문서는 **v0.1 싱글플레이 프로토타입 시점의 기록**이며,
> 지금은 서버·PvP(정복 맵)·레이드·NPC 성 침략까지 전부 구현된 뒤라 아래 "범위"·"비목표"
> 서술을 포함해 여러 항목이 현재 빌드와 다르다. **최신 사양은 [SYSTEM_DESIGN.md](SYSTEM_DESIGN.md)를
> 본다.** 이 문서는 의도적으로 더 갱신하지 않고 최초 설계 의도를 보존하는 용도로만 남겨둔다.

> 장르: SNG 도시 건설 전략 (레퍼런스: 클래시 오브 킹즈) · 컨셉: 그리스·로마 신화
> 범위(v0.1 당시): **싱글플레이 웹 프로토타입** — 서버, PvP, 길드, 실시간 매칭 등 멀티플레이 요소는 전부 비목표.
> 참고: 이 문서는 `game-world-design` 스킬의 표준 방법론(내러티브 3막 구조·적대 AI 반응·윤리적 선택 회수 등, 스토리 기반 액션/어드벤처 장르 전제)을 뼈대로 삼되, 실제 장르인 "타임어택 없는 경영/수집형 SNG"에 맞게 항목을 덜어내고 재구성했다. 명분 없는 서사 강제 대신, 이 장르에서 실제로 재미를 만드는 요소(자원 순환, 확률 기반 수집, 배치 최적화)에 집중.

## 1. 한 줄 정의 & 플레이어 프라미스

- **플레이어 정체성**: 그리스·로마 신화 세계의 신생 도시국가를 세운 군주.
- **핵심 행동**: 건물을 짓고 → 자원을 순환시키고 → 여관에서 영웅을 뽑아 → 건물에 배치해 도시를 굴린다.
- **세계의 반응**: 자원이 쌓이면 건설/훈련이 가능해지고, 영웅을 배치하면 해당 건물의 생산·훈련 속도가 즉시 눈에 보이게 빨라진다.
- **목표 감정**: "다음 여관 초기화까지 5분, 그 사이에 뭘 더 최적화할 수 있을까"— 가벼운 강박과 수집의 쾌감.

## 2. 장르 원칙 — 무엇을 빌리고, 무엇을 일부러 안 빌리는가

같은 장르(도시 건설+수집형 SNG) 선례: **클래시 오브 킹즈**, **라이즈 오브 킹덤즈**.
공통 핵심 동사(이 3~5개만 프로토타입의 뼈대로 삼는다):

1. **건설(Build)** — 건물 슬롯에 건물을 짓거나 업그레이드
2. **배치(Assign)** — 영웅을 건물에 배치해 내실 보너스 획득
3. **수집(Roll)** — 여관에서 영웅을 뽑는다 (가챠)
4. **승급(Ascend)** — 업적으로 영웅의 별 등급을 올린다
5. **비축(Stockpile)** — 자원을 생산·보호(창고)하여 다음 건설/훈련에 사용

**일부러 안 빌리는 것**: 실시간 PvP 공성전, 길드/동맹, 행군·정찰, 랭킹 서버, 가챠에 실결제 연동. 이 프로토타입은 "내 도시 안에서 벌어지는 순환"만 검증한다.

## 3. 첫 화면에 실제로 뜨는 문구 (전제 상단 노출 문안)

- 타이틀 화면(게임 로드 시 항상 최초 진입): **"신들이 지켜보는 땅에, 첫 도시를 세운다."** + "▶ 게임 시작" 버튼(저장된 진행 상황이 있으면 이어서 시작).
- 첫 튜토리얼 말풍선(강제 1회, 후속 스킵 가능): **"성 옆 빈 터를 눌러 농장을 지어보자. 곧 곡물이 쌓일 것이다."**
- 여관 최초 진입 시: **"신탁이 여덜 명의 영웅을 보냈다. 별의 수가 곧 그들의 힘이다."**
- 종료 화면("🚪 종료" 버튼): **"플레이해주셔서 감사합니다. 진행 상황이 저장되었습니다. 이제 이 탭을 닫으셔도 됩니다."** — 승패 조건이 없는 경영 SNG이므로 "게임 오버"가 아니라 저장 완료 안내 + 탭 종료 유도로 마무리한다.

## 4. 3단 성장 곡선

| 구간 | 종료 표식(관찰 가능) | 새로 할 수 있는 것 |
|---|---|---|
| **정착기** | 성 3레벨 달성 & 첫 3성 이상 영웅 확보 | 건물 8종 모두 최초 1회 건설 가능, 여관 유료 리셋 해금 |
| **확장기** | 아카데미 3레벨(연구 2종 완료) | 영웅 강화(중복 조각 소비) 해금, 건물 배치 슬롯 2번째 오픈, 월드맵 레벨 1~5 성 침공 가능 |
| **완성기** | 영웅 도감 30명 수집 | 7성 이상 영웅 등장 확률 구간 진입, 방어탑 레벨업으로 원정 부대 강화율 상승, 월드맵 고레벨 성까지 도전 가능 |

(정착기→완성기 사이, 플레이어가 "할 수 있는 행동"의 차집합: 배치 슬롯 수, 승급 가능 여부, 뽑기 확률 구간 — 단순 숫자 증가가 아니라 실제로 새로 가능해지는 조작이 늘어난다.)

## 5. 코어 루프 (2계층)

**짧은 루프 (5~30초)**: 화면 훑기(자원 게이지/여관 타이머 확인) → 건물 클릭 → 액션 선택(건설/수집/배치) → 즉시 피드백(숫자 변화, 아이콘 애니메이션) → 자원·타이머 갱신.

**긴 루프 (1~5분)**: 여관 5분 타이머 한 바퀴 = 의사결정 단위. "지금 자원을 리셋에 쓸까, 건설에 쓸까?" → 새 영웅 8명 등장 → 배치 재조정 → 다음 타이머까지 생산 곡선 변화 관찰.

- **초보 플레이어**: 아무 건물에나 영웅을 배치하고, 뽑히는 대로 리롤 없이 소비.
- **숙련 플레이어**: 영웅의 "건물 보너스 태그"를 확인해 병영 특화 영웅은 병영에, 채석장 특화는 채석장에 배치. 리롤 재화를 자원 부족 시점 직전에 아껴서 쓴다.
- **숙련도 유형**: (b) 재생형 판단 — 매번 여관에 등장하는 8명의 조합이 다르므로 매 타이머마다 "이번엔 뭘 우선할지" 다시 판단해야 함.

## 6. 건물 시스템 (장르 최소 계약: 시간 진행 · 자원 흐름 · 피드백 지연)

| 건물 | 역할 | 배치 시 영웅 보너스 예 |
|---|---|---|
| 성(본성) | 도시 레벨의 기준, 전체 건물 슬롯 해금 | 전체 생산 +% (군주형 영웅) |
| 병영 | 병력 훈련 | 훈련 시간 단축 |
| 농장 | 식량 생산 | 식량 생산량 +% |
| 벌목장 | 목재 생산 | 목재 생산량 +% |
| 채석장 | 석재 생산 | 석재 생산량 +% |
| 자원 보호소(창고) | 자원 저장 상한 & 약탈 방지(단, 프로토타입엔 약탈 없음 → 상한만 기능) | **영웅 배치 대상 아님** — 상한은 레벨에만 비례 |
| 아카데미 | 연구(생산 배율, 강화 재료 수급과는 무관 — 강화는 조각만 있으면 가능) | 연구 속도 단축 |
| 방어탑 | **월드맵/야생 지역으로 출정하는 내 부대의 방어력을 레벨×연구 배율로 강화(%)**. "적의 역습을 막는" 수치가 아니라 "내가 원정 나갈 때 받는 버프"다 | **영웅 배치 대상 아님** — 레벨과 연구로만 강화율 상승 |
| 감시탑 | 여관 갱신 알림 / 야생 몬스터 정보 단계적 공개(레벨 L → 몬스터 레벨 2L+1까지 상세 스탯 확인 가능, 그 이상은 Lv.? 로 표시) | **영웅 배치 대상 아님** |
| 여관 | 영웅 뽑기 전용 | (영웅 배치 대상 아님 — 뽑기 전용 시설) |
| 성벽 | 도시의 상징적 수비력 표시(전투에 직접 관여하지 않음) | 수비력 +% |

**인과 모델**: `자원 보유량 + 건설/훈련 선택 + 건물 레벨·배치 영웅 보너스 → 생산량 갱신 + 진행 게이지로 즉시 표시`

## 7. 영웅 시스템 (여관)

- 여관 슬롯 수는 여관 레벨에 비례해 **5~8명**(레벨 1~5: 5명, 6~10: 6명, 11~15: 7명, 16+: 8명)까지 늘어남.
- **5분마다 자동 초기화**(전체 칸 교체). 재화(금화)를 내면 즉시 리셋 가능 — 비용은 마지막 리셋 이후 경과 시간이 짧을수록 비싸짐(연속 리롤 억제).
- 등급(★1~★8)별 등장 확률 차등, 등급이 높을수록 전투 특성치·건물 보너스 수치가 큼.
- **영웅 도감**: 그리스·로마 신화 인물 148명(그리스/로마 동일신 중복 병합 완료) + 창작 NPC 151명 + 까미 1명, 총 300명. 수집 시 도감에 영구 등록(중복 뽑기는 해당 영웅의 "강화 재료" 조각으로 환산).
  - 등급별 인원: ★1 50 · ★2 50 · ★3 45 · ★4 57 · ★5 40 · ★6 32 · ★7 17 · ★8 9(까미 포함, 순수 ★8은 8명)
  - 등급 배정은 신화 속 업적·위계 기준(우주 지배자급=★8 → 올림포스 주신급=★7 → 위업이 큰 신/영웅=★6 → 서사시 주역 인간=★5 → 군소 신격=★4). 창작 NPC는 ★1~4에 분산.
- **영웅 강화(별 승급 아님)**: 별 등급(rarity)은 뽑힌 순간 고정되며 이후 절대 바뀌지 않는다. 대신 같은 영웅을 중복으로 얻어 쌓은 조각을 소비해 **강화(0강~5강)**할 수 있다. 강화 1단계당 전투 스탯·건물 보너스 효과가 15%씩 누적 증가(예: 5성 0강 → 조각 소비 → 5성 1강). 아카데미 없이도 조각만 있으면 강화 가능.
- 각 영웅은 **전투 특성**(공격/방어/체력 3수치 + 특성 태그 1개) + **건물 보너스**(배치 건물 종류 + 보너스 % 1개) 중 하나를 가짐(둘 다는 아님). 단, 방어탑·자원보호소는 건물 보너스 대상에서 제외되어 있어 해당 건물을 노리던 영웅은 전투 특성으로 대체되어 있다.

### 7-2. 리셋 비용 (금화)

`리셋 비용 = 50 × max(1, 5 − 마지막 리셋 이후 경과분)` (경과 5분 이상이면 자동 초기화이므로 비용 0으로 사실상 무료)

→ 초기화 직후 리셋하면 최대 250골드, 4분 기다렸다 리셋하면 50골드. 감시탑 레벨업 시 이 비용에 %감소 적용.

## 8. 특수 영웅 — 까미 (★8, 유니크)

- **설정**: 강사(플레이어 세계관의 재야 현자로 등장)가 애지중지 키우는 고양이가 어쩌다 신격을 얻은 존재. 신화 인물이 아니라 **이 게임 세계에만 존재하는 조커 카드**.
- **역할**: 개그 겸 "전설의 조커" — 등장 확률 0.05%(사실상 이스터에그), 뽑히면 스탯(공/방/체 각 999)이 다른 어떤 영웅보다도 압도적으로 높고, 전투 특성으로 **부대 공격력 +60%**라는 파격적인 수치를 가진 유일한 영웅.
- **밸런스 처리**: 확률을 극단적으로 낮게 유지해 "정상적으로는 도감 완성 훨씬 이후에나 만날 수 있는 존재"로 두고, 등장 시 화면 전체에 별도 이펙트(웃음 포인트)를 넣어 희귀성을 체감시킨다. 도감에는 "출처 불명 / 강사님의 고양이"로 기재.
- **대체 불가 여부**: 의도적으로 "거의 무조건 기용"이 맞다 — 조커 카드는 밸런스보다 유머와 수집 순간의 쾌감이 우선이라는 설계 판단. 단, 도감 300명 중 1명일 뿐이므로 코어 루프(건설·배치·수집)를 대체하진 않는다.

## 9. 결정 깊이 예시 (표준 방법론 요구 항목)

**결정 지점**: 여관 자동 초기화 30초 전, 손에 금화 120이 있다. 지금 리셋할까?

| 행동 | 금화 40 보유 | 금화 120 보유 | 금화 300 보유 |
|---|---|---|---|
| 리셋 안 하고 대기 | 최적 (리셋 비용 감당 안 됨) | 무난 | 손해(자원 낭비) |
| 즉시 리셋(비용~50) | 불가 | 최적 (여유 있고 자동초기화까지 오래 남음) | 가능하지만 비효율 |
| 리셋 대신 건설에 사용 | 최적 | 상황에 따라 최적(건설 임박 시) | 무난 |

→ "즉시 리셋"이 최적인 지점은 금화 보유량이 리셋 비용의 약 2.5배를 넘는 시점에서 뒤집힌다. 자동 승리 동작 없음.

## 10. 품질 체크 (go/no-go)

| 질문 | 판정 | 근거 |
|---|---|---|
| 세계/상대가 핵심 시스템으로 반격하는가 | **부분 go(단, 실시간 상대 아님)** | 야생 몬스터와 월드맵 NPC 성이 고정된 스탯으로 반격(피해 계산)하지만, 이들은 실시간으로 사고하는 상대가 아니라 절차 생성된 스탯 블록이다. 내 도시가 역으로 침공당하는 일은 없음(PvP/공성전 비목표 원칙 유지). |
| 매 사이클마다 진짜 선택이 있는가 | **go** | 매 5분 사이클 리셋 여부·자원 배분·배치가 자원량에 따라 최적해가 바뀜(9번 표). |
| 시그니처 판타지가 반복 가능한 핵심 동사에 있는가 | **go** | "여관에서 뽑고 배치해 도시가 굴러가는 걸 본다"가 매 사이클 반복됨. |
| 핵심으로 내세운 시스템이 지배당하지 않는 선택지를 제공하는가 | **go** | 등급별 확률·건물별 보너스 태그가 있어 "무조건 이 건물에 몰아넣기"가 항상 최적이 되지 않음(보너스 종류가 건물마다 다름). |

## 11. 프로토타입 범위 (비목표 명시)

**포함**: 건물 11종 배치/건설/다단계 레벨업(최대 20레벨), 자원 4종(식량/목재/석재/금화) 생산·소비 및 초당 생산량 실시간 표시, 여관 가챠(5분 타이머, 레벨별 5~8슬롯, 유료 리셋, 후보 스탯·특성 노출), 영웅 도감 300명(까미 포함), 영웅 강화(중복 조각 소비, 최대 5강), 영웅→건물 배치와 보너스 수치 반영, 병영 병사 훈련과 군대(부대 3개) 편성, 야생 지역 몬스터 전투, **월드맵(레벨 1~20 NPC 성 침공 — 절차 생성 성, 승리 시 그 성이 그동안 모은 자원 전액 약탈, 점령 없이 재도전 가능)**, 타이틀/게임 시작·종료 화면, 설명서(건물 역할 안내), 보유 영웅 열람 화면.

**비목표**: 실시간 대인전(PvP)·서버·랭킹 — 월드맵의 성은 실시간으로 반응하는 상대가 아니라 절차 생성된 NPC이며, 내 도시가 다른 플레이어나 NPC에게 역으로 공격받는 일도 없다. 그 외 길드/동맹, 행군 중 정찰·매복, 결제 연동, 정교한 사운드/풀 애니메이션.

## 12. 최소 검증 질문

가장 위험한 가정: "5분 타이머 + 유료 리셋"이 플레이어에게 "기다릴까 지를까"라는 실제 갈등을 만드는가, 아니면 그냥 무시되는가?
→ 검증: 프로토타입에서 리셋 버튼 비용이 실시간으로 표시되고, 자동 초기화 카운트다운이 항상 보이는지 확인. 관찰 포인트: 유저가 카운트다운을 보고 "조금만 더 기다리자"고 판단하는 행동이 나오는가.

## 13. 문체 & 지역화

- 대상 언어: 한국어 단일 (프로토타입 1회차 기준, 추가 로컬라이즈는 비목표)
- 문체: 신화적 격조 + 과하지 않은 유머(까미 관련 텍스트만 예외적으로 가벼움). UI 라벨은 간결한 명사형("건설", "배치", "뽑기").
