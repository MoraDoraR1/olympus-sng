## 1. 한 줄 정의

> **신들이 지켜보는 땅에서, 내 도시를 키우고 남의 도시를 노린다.**
> 그리스·로마 신화를 배경으로 한 **전략 SNG** — 자원을 모아 성을 올리고, 여관에서 신화 속
> 영웅을 뽑아 부대에 태우고, 몬스터를 사냥하고, 다른 유저의 성을 약탈하거나 동료의 성을 지원한다.

## 2. 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 전략 SNG (도시 건설 + 수집형 + 비동기 대인전) |
| 플랫폼 | 웹 브라우저 (PC·모바일 브라우저 공용) |
| 기술 구성 | 빌드 도구 없는 정적 클라이언트(HTML/CSS/JS) + Cloudflare Workers 백엔드(Hono + D1 + Durable Objects) |
| 대인전 방식 | **비동기 PvP** — 상대가 접속해 있지 않아도 서버(Durable Object의 Alarm API)가 미션 도착 시각에 정확히 깨어나 전투를 판정 |
| 세션 길이 | 짧은 루프 5~30초 / 긴 루프 10분(여관 주기) / 원정 수 분~수십 분 |
| 언어 | 한국어 단일 |
| 과금 | 없음 (비목표) |

## 3. 레퍼런스 — 무엇을 빌리고, 무엇을 일부러 안 빌리는가

**1순위 레퍼런스: 갓퀘스트 — 오르페우스의 선택**
보조 레퍼런스: 클래시 오브 킹즈, 라이즈 오브 킹덤즈

| 요소 | 빌린다 / 안 빌린다 | 우리의 선택 |
|---|---|---|
| 신화 IP를 영웅 수집으로 푸는 방식 | **빌린다** | 그리스·로마 신화 인물 + 창작 NPC를 합쳐 **300명 도감**. 등급이 곧 신화 속 위계 |
| 성 중심의 단일 성장 축 | **빌린다** | **성 = 플레이어 레벨.** 모든 건물은 성 레벨을 절대 넘지 못한다 |
| 자원 3종 + 화폐 구조 | **빌린다** | 식량·목재·석재 + 금화 |
| 비동기 출정·약탈 | **빌린다** | 출정 → 이동 시간 → 서버 판정 → 귀환. 오프라인 상대도 정확한 시각에 처리 |
| 지원군(원군) 파병 | **빌린다** | 동료 성에 주둔시켜 수성 전력에 합산. 대인전이 "때리기"만이 아니게 만드는 핵심 |
| 실시간 공성전 | **안 빌린다** | 실시간 매칭·중계는 웹 프로토타입 범위를 넘어선다 |
| 길드/동맹 시스템 | **안 빌린다(1차)** | 지원군 파병으로 협력의 재미만 먼저 검증한다 |
| 확률형 아이템 실결제 | **안 빌린다** | 가챠는 있으나 **인게임 재화(금화)로만** 돌린다 |
| 성 점령·영토 소유 | **안 빌린다** | 약탈은 되지만 점령은 없다. 패배해도 성을 잃지 않아 복귀 장벽이 낮다 |

**가장 중요한 차별점**: 이 장르의 표준인 "체력/행동력으로 플레이 시간을 끊는 장치"를 쓰지
않는다. 대신 **여관 10분 주기**와 **부대 이동 시간**이 자연스러운 호흡을 만든다.

## 4. 핵심 시스템 4축

```
        ┌──────────────┐
        │   건물 레벨업  │  성이 모든 건물의 상한 = 플레이어 레벨
        └───────┬──────┘
                │ 자원·해금
     ┌──────────┼──────────┐
     ▼          ▼          ▼
 ┌───────┐  ┌───────┐  ┌────────────┐
 │  영웅  │  │  전투  │  │  대인 전략  │
 │ (여관) │─▶│(부대)  │─▶│ 공격·지원   │
 └───────┘  └───────┘  └────────────┘
     ▲                        │
     └────────  약탈 자원 ◀────┘
```

### 4-1. 영웅 — "누가 뽑히느냐가 이번 10분을 결정한다"

- **★1~★8 + 조커 1명**, 총 300명. 등급은 신화 속 위계 그대로 (★8 = 크로노스·제우스급)
- 여관에서 **10분마다 자동 초기화**되는 후보 목록에서 금화로 영입
- 영웅은 두 가지로 쓰인다 — **건물에 배치**(생산·훈련 보너스) 또는 **부대에 편성**(전투력)
- 중복 영웅은 **조각**으로 환산해 강화(0~5강). 별 등급은 절대 오르지 않는다 —
  "레어를 갈아 레전드를 만드는" 인플레를 원천 차단

### 4-2. 전투 — "영웅 3명 + 병사 한 무리 = 부대 하나"

- 부대 **3개**를 동시에 굴린다. 부대마다 영웅 3명 + 병종 5종을 섞어 편성
- 대상은 세 종류: **야생 몬스터**(상시 8슬롯, Lv.1~30) / **NPC 성 20개**(Lv.1~20,
  "🏯 침략" 버튼/모달에서 열람·공격) / **보스 레이드**(6종 선행 체인, 필드·NPC 성보다
  훨씬 강하도록 설계)
- 이기면 병력 손실 최대 60%, 지면 최대 100% — **지는 쪽이 훨씬 아프다.** 무리한 출정에
  실제 대가가 있어야 감시탑으로 적을 살피는 행동이 의미를 갖는다

### 4-3. 건물 레벨업 — "성이 곧 나의 레벨"

- 건물 **11종**, 각 **최대 Lv.20**
- **모든 건물은 성 레벨을 넘을 수 없다.** 성을 올리지 않으면 아무것도 자라지 않는다
- 거기에 건물 간 선행 조건이 겹친다 (병영은 농장이, 채석장은 벌목장이, 여관은 아카데미가
  각각 일정 레벨 이상이어야 한다) — 한 건물만 몰아 올리는 플레이를 막는 장치
- 아카데미 연구 **30종 × Lv.5**가 생산·전투·영웅 획득 확률에 영구 배율로 얹힌다

### 4-4. 대인 전략 — "공격과 지원, 둘 다 진짜 선택이다"

- **정복 맵 200×200** 위에 각 플레이어의 성이 한 칸씩 놓인다 (성 Lv.5부터 진입)
- **공격**: 상대 자원의 10%를 약탈. 거리에 비례한 이동 시간이 걸려 "지금 때리면 언제 도착하는지"가
  전략이 된다
- **지원**: 동료 성에 부대를 주둔시키면 그 성이 공격받을 때마다 수성 전력에 자동 합산된다
- **방어 수단**: 보호막(30분/1시간/2시간)·성 이동 텔레포트를 금화로 구매
- **규칙 하나가 이 시스템의 성격을 정한다** — 공격자가 지원군보다 먼저 도착하면,
  아직 도착하지 못한 지원군은 전부 자동 철수한다. **지원은 늦으면 의미가 없다.**

## 5. 코어 루프

**짧은 루프 (5~30초)** — 자원 게이지와 여관 타이머 확인 → 건물 클릭 → 건설/레벨업/배치 →
숫자가 즉시 변하는 것을 확인

**중간 루프 (10분)** — 여관 초기화 한 바퀴. "이번 후보에 쓸 만한 게 있나? 지금 리셋할까,
그 금화를 건설에 쓸까?"

**긴 루프 (수십 분~수 시간)** — 부대를 원정 보내고, 그동안 도시를 굴리고, 돌아온 부대의
전리품으로 다음 성 레벨을 연다. 그 사이 내 성이 약탈당했을 수도 있다.

## 6. 핵심 재미 3가지

1. **뽑기의 변동성** — 슬롯마다 독립 추첨이라 한 번에 ★6 이상이 두 명 나올 수도, 열 번을
   돌려도 안 나올 수도 있다. 이 편차가 "리셋할까 말까"를 매 사이클 진짜 고민으로 만든다.
2. **배치 최적화** — 영웅은 유한하고 건물은 많다. 벌목장 특화 영웅을 성에 넣으면 손해다.
   건물당 3명 상한이 있어 "몰빵"이 항상 정답이 되지 않는다.
3. **비동기 대인 긴장감** — 로그인했더니 자원이 10% 사라져 있는 경험, 그리고 친구의 성을
   지켜주러 부대를 보냈는데 한 발 늦은 경험. 혼자 하는 경영 게임에는 없는 감정이다.

## 7. 시그니처 모먼트

- **여관 카운트다운 0초** — 후보 카드가 동시에 뒤집히며 새로 깔린다. 이 게임에서 가장 자주
  반복되는, 가장 SNG다운 순간
- **까미 등장** — 0.05% 확률의 조커. 화면 전체가 반짝이고 고양이 울음이 한 번 울린다
- **약탈당한 아침** — 접속하자마자 뜨는 전투 보고서. "누가, 언제, 얼마나 가져갔는가"
- **아슬아슬하게 도착한 지원군** — 공격 도착 3초 전에 주둔에 성공해 수성에 이긴 순간

## 8. 비목표 (이번 범위에서 명확히 제외)

- 실시간 대인 공성전, 실시간 매칭, 관전
- 길드·동맹 시스템, 채팅
- 결제 연동, 확률형 상품 판매
- 다국어 로컬라이즈
- 성 점령·영토 지배 (약탈까지만)
- 풀 애니메이션·보이스·BGM 제작

## 9. 현재 개발 상태 한눈에

**핵심 시스템은 이미 전부 동작하고, 실제로 배포되어 있다.** 건물 11종, 영웅 300명,
병종 5종, 연구 30종, 몬스터·NPC 성 침략·레이드, 그리고 비동기 PvP(공격·지원·약탈·보호막)까지
구현되어 있다. 백엔드는 Node.js/SQLite → (한때) Firebase 시도 → **현재 Cloudflare
Workers(D1 + Durable Objects)**로 정착했고, `main` 브랜치에 푸시할 때마다 GitHub Actions가
자동으로 배포한다(`.github/workflows/cloudflare-deploy.yml`).

남은 것은 **새 기능이 아니라 검증과 다듬기**다 — 다인 PvP 실전 검증, 후반 밸런스,
온보딩, 콘텐츠(영웅 초상 등). 자세한 구분과 일정은 [DEV_PLAN.md](DEV_PLAN.md)를 본다.
