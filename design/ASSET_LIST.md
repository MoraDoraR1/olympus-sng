# ASSET_LIST — 리소스 제작 목록 & 우선순위

> 이 문서는 실제 이미지 리소스로 교체할 때 무엇을, 몇 장, 어떤 규격으로, 어떤 순서로 만들지 정리한 체크리스트다.
> 배치·모션 규칙(그림자, idle-float, 2.5D 틸트 등)은 `UI_LAYOUT_RULES.md`를 함께 참고.

## 진행 상황

- **1~10번(전체) 완료**: PNG 대신 **절차적 SVG**로 제작(래스터 아트 생성 도구 없이 코드로 직접 벡터 제작). 생성기는 `tools/gen-assets.mjs`(실행: `node tools/gen-assets.mjs`) — 팔레트·도형 규칙을 바꾸면 전체 세트를 일괄 재생성할 수 있다. 결과물은 `assets/board/`, `assets/buildings/`, `assets/monsters/`, `assets/worldmap/`, `assets/title/`, `assets/heroes/`에 저장.
  - 이모지를 SVG `<text>`로 그대로 옮기면 헤드리스/일부 환경에서 아예 렌더링되지 않는 것을 확인 → 모든 장식은 순수 벡터 도형(원·선·다각형)으로만 제작.
  - 월드맵 배경은 성채가 화면 전역에 흩뿌려지는 배치 특성상 지평선/하늘이 있는 "풍경" 구도 대신 완전한 탑다운 지형으로 제작.
  - 영웅 초상화(10번, 300명)는 4절이 권고한 "파츠 조합형"을 그대로 구현: `data/heroes.js`의 각 영웅 `id`를 시드로 결정적 난수를 돌려 피부색·머리색·머리모양·수염·의상색을 조합 — 재생성해도 항상 같은 결과가 나온다. 등급이 오를수록 머리띠→월계관→금관+오라로 장신구가 화려해지고, ★8 신급 9명(까미 포함)은 이름에 맞는 상징 아이템(제우스=번개, 포세이돈=삼지창 등)을 개별 지정. 까미는 사람이 아니라 고양이 얼굴로 별도 제작.

## 0. 공통 제작 규칙

- 포맷: 배경이 있는 것(바닥 텍스처, 월드맵 배경) 제외하고는 전부 **알파 채널 있는 투명 PNG**.
- 그림자는 이미지에 굽지 않는다 — CSS `filter: drop-shadow(...)`가 실시간으로 씌우므로 배경 투명 필수.
- 아이콘류(건물/몬스터/월드맵 성)는 idle-float 애니메이션(상하 6px)을 받으므로 **정면·좌우 대칭 실루엣**으로 제작.
- 보드는 2.5D로 살짝 기울어져 있지만(perspective+rotateX), 개별 스프라이트는 **평범한 정면 뷰로 제작**하면 된다 — 기울기는 CSS가 전체 평면에 일괄 적용하므로 에셋 자체를 원근 변형해서 그릴 필요 없음.
- 해상도: CSS 표시 크기의 2배로 제작 권장(레티나 대응).
- 파일 경로 제안: `assets/buildings/{type}_{tier}.png`, `assets/monsters/{key}.png`, `assets/heroes/{id}.png`, `assets/worldmap/*`, `assets/board/*`, `assets/ui/*`.

## 3. 몬스터 · 월드맵 · UI 규격

- 몬스터: 72×72px, 실루엣 뚜렷하게(그림자 필터가 실시간으로 씌워짐). 일반 10종(켄타우로스·사티로스·하피·키클롭스·고르곤·미노타우로스·그리핀·카르키노스·라미아·엠푸사) + 엘리트 3종(메두사·히드라·케르베로스).
- 월드맵 배경: 1600×1000px 내외, `background-size:cover`로 한 장 통짜 사용. "대륙 지도" 느낌.
- 월드맵 성채 아이콘: 내 도시용 1개(살짝 크게) + NPC 성용 1개, 레벨 구간별 색 배지로 난이도만 구분(아이콘 자체는 공용).
- 타이틀 배경: 은은한 신화적 실루엣(올림포스 산/구름), 텍스트 가독성 위해 방사형 그라디언트를 위에 얹을 여지를 남길 것.

## 4. 영웅 초상화 — 300명 대응 전략

현재 영웅 카드는 **등급별 공용 이모지**(🧑/🧝/🗡️/🧙/👑/⚡/🦉/🌟, 까미만 🐱)로만 구분되고 개인 초상은 전혀 없다. 300명 전원 개별 원화는 비현실적이므로 **등급 순으로 단계적 제작**을 권장한다.

| 단계 | 대상 | 인원 | 비고 |
|---|---|---|---|
| 1단계 | ★8 | 8명 | 제우스·헤라·포세이돈 등 최상위 신 — 노출 빈도·상징성 최고, 가장 먼저 |
| 1.5단계 | 까미 | 1명 | 조커 캐릭터, 재미 요소라 초반에 함께 해도 좋음 |
| 2단계 | ★7 | 17명 | 올림포스 주신급 |
| 3단계 | ★6 | 32명 | 위업이 큰 신/영웅 |
| 4단계 | ★5 | 40명 | 트로이 전쟁·건국 서사 인물 |
| 5단계 | ★4 | 57명 | 절반은 군소 신화 인물, 절반은 창작 NPC |
| 6단계 | ★1~3 | 144명 | 전원 창작 NPC — 개별 원화 대신 **파츠 조합형**(머리/복장/무기 몇 종을 배치·문화권별로 섞어 조립) 방식도 고려할 만함 |

- 규격: 정사각형 200×200~300×300px, **인물만 투명 배경**(카드가 이미 등급색 배경을 깔아줌).
- 카드/코덱스 양쪽에서 같은 파일 재사용 가능(별도 저해상도 버전 불필요).

## 5. 총 이미지 파일 수 (영웅 제외)

바닥(1) + 성벽 9-slice(1세트) + 랜드마크(6) + 고정건물(12) + 선택건물(12) + 빈부지(1~2) + 몬스터(13) + 월드맵(3) + 타이틀(1~2) ≈ **약 50장**. 이것만 채워도 체감 완성도가 크게 오르고, 영웅 초상은 그 이후 등급 순으로 별도 트랙으로 진행하면 된다.
